# Limits

Single-user local demo; no public authentication/authorization. One crop yields one primary class, with manual correction. Scores are uncalibrated. No automatic ingredient/mass/detection inference. Only one sourced representative nutrition profile is currently curated; other foods may remain unavailable. CUDA hardware exists but installed PyTorch is CPU-only. Training and dataset status change during execution: consult IMPLEMENTATION_STATUS.md, not historical design targets. No local Vietnamese domain-shift photos have been collected. Short POC experiments are not full-101 or converged model benchmarks.
