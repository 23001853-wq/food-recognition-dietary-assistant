# Visual assets

`food_photography.jpg` is a byte-for-byte copy of the user's original `.streamlit/3.jpg`.
It is displayed in the Home banner using CSS positioning; the original image was not
edited or generated. `.streamlit/1.jpg` and `2.jpg` guide layout and colors only and are
not reproduced as application screenshots or used as background images.

`food_hero.svg` is the earlier original vector illustration, retained as a project asset.
